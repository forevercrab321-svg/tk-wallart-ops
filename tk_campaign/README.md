## 4. 发布节奏（起号期 4 周）

- 频率：每天 1-2 条，每周 ≥5 条
- 时段：美东晚 7-10 点（北京时间早 7-10 点）
- 同一视频换 Hook/音乐重发 2-3 次测试
- 验证标准：发布 2 小时后自然播放 >500 且完播率 >30%

## 5. B 线启动清单（解决身份后）

1. 选品：清洁小工具（缝隙清洁胶/电动清洁刷）或宠物美容工具（洁爪杯/除毛梳）
2. 样品：联盟市场申请免费样品
3. 内容结构（15-30秒）：0-3秒痛点 Hook → 3-20秒 before/after → 最后3秒“点左下角小黄车”
4. 铁律：真人真声实拍、#ad 披露、不碰疗效宣称、SPS<2.5 的店铺不推
5. CHR 风控：起始200分，跌破150限流、100冻结佣金；同类违规90天满6次永封
